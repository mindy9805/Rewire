# Rewire｜神經可塑性的學習與練習

> 理解神經可塑性，練習覺察思考、情緒與行為。

以 Nicole Vignola《Rewire》為學習主軸的繁體中文互動式學習網站。結合互動電子書、知識筆記、視覺化學習、個人反思與行為練習；不需登入、沒有後端，所有個人資料只存在使用者的瀏覽器（LocalStorage）。

- 正式網址：`https://mindy9805.github.io/Rewire/`
- 技術：React 18、TypeScript、Vite 5、Tailwind CSS 3、React Router（HashRouter）、Lucide Icons、Recharts、PWA（manifest + Service Worker）

### 維護慣例

- **改文字**：只改 `src/content/`；元件不寫死內容。
- **改顏色或字級**：改 `src/styles/tokens.css`，深色模式在同一個檔案。
- **動畫**：keyframes 統一寫在 `tailwind.config.js`，元件用 `motion-safe:animate-*`；需要用 JS 判斷時呼叫 `src/lib/motion.ts` 的 `prefersReducedMotion()`，系統偏好與站內「關閉動畫」都會生效。
- **小慶祝**：呼叫 `src/lib/celebrate.ts` 的 `celebrate()`，`LeafBurst` 會播放飄葉，關閉動畫時自動略過。
- **按鈕**：實心的 `.btn-primary` 只用在「動作」，每個畫面最多一個；篩選、設定、多選這類「選項」一律用 `.btn-toggle`（以 `aria-pressed` 表示選取，選中時有 ✓），次要動作用 `.btn-secondary`／`.btn-ghost`。
- **解鎖提示**：`GrowthWatcher` 會把 0.6 秒內陸續解鎖的徽章、植物、景觀合併成一則提示，只播一次飄葉。
- **完成時刻**：章節、14 天練習的某一天、7 Habits 章節完成時，使用 `<CompletionCard />`（帶走一句話＋一個下一步＋存到筆記），不另外跳提示。
- **英文小標**：只放在總覽頁（學習、我的、主題學習、知識實驗室）與內容本身的英文名稱，其他內頁不加。
- **深色區塊**：需要深綠底、淺色字的區塊用 `bg-deep text-ondeep`（深色模式仍維持深綠）；不要用 `bg-forest` 配寫死的淺色字。鼠尾草綠當文字時用 `text-sageink`（對比足夠），`text-sage` 只給圖示與裝飾。
- **頁面標題**：每頁一個 h1；用 `SectionTitle` 當頁面標題時傳 `level={1}`。
- **按需載入**：新頁面在 `App.tsx` 的 `loaders` 加一行即可；首頁顯示約 3 秒後會在背景預先下載其他頁面，離線也能使用。
- **水彩插畫**：小芽（`play/Buddy.tsx`）與花園植物（`play/PlantSvg.tsx`）共用 `play/watercolor.tsx` 的水彩濾鏡與調色盤，新增植物時沿用 `wash`／`bloom`／`ink` 三種效果。
- **朗讀**：`lib/speech.ts` 第一優先「Google 國語（臺灣）」，其次「台灣中文＋女聲＋自然語音」；不列出中國大陸聲音（zh-CN 與未標地區的 zh），香港／澳門／新加坡／馬來西亞的中文另列「其他地區中文」。iPhone／iPad 上沒有 Google 聲音，會改用美佳。長文字依句號切段；使用者可在「資料與隱私 → 朗讀聲音」指定聲音、試聽與使用「朗讀檢查」。實際可用的聲音由裝置提供。
  - **手機規則（重要）**：`speak()` 必須在點擊或按鍵事件中**直接**呼叫，不可放在 `useEffect`、`await`、`setTimeout` 之後，否則 iPhone 會無聲擋下。語音清單未載入時不等待，直接以 `zh-TW` 朗讀。
  - 進入朗讀模式的連結加上 `onClick={unlockSpeech}`；介面用 `<SpeechStatus />` 顯示朗讀中／排除提示。
  - **聽不到聲音的排查**：「朗讀檢查」記錄實際發聲時間（太快結束＝語音資料問題；時間正常＝靜音或音量），並提供非語音的「播放測試音」（`lib/testTone.ts`）。聲音選單有「相容模式」（`voiceURI='system'`），不指定聲音、只設 `lang='zh-TW'`。`unlockSpeech()` 不設 `volume=0`。**靜音開關**：iPhone 的朗讀會被側邊靜音開關消音（實測：切到有聲音就正常；曾嘗試同步播放無聲 `<audio>` 與設定 `audioSession`，無效，已移除）。網頁無法繞過，朗讀中在 iOS 顯示提醒。
- **圖解（內容視覺化）**：學習頁先以圖解呈現、完整文字收在「看完整說明」，內容一字不刪。元件在 `src/components/visual/`：
  - `KeyPointCard` 重點卡、`IconCardGrid` 圖示卡、`LoopDiagram` 循環圖、`ChainDiagram` 因果鏈（只用在有先後順序的內容）、`SpectrumBar` 光譜對照、`CompareColumns` 左右對照、`StepCards` 步驟卡、`EvidenceBadge` 證據標籤、`Timeline` 時間軸、`RangeChart` 研究數據範圍圖、`WatercolorSpot` 水彩小插畫、`MoreDetails` 看完整說明。
  - 開發時執行 `npm run dev` 後開啟 `#/dev/visual` 可預覽所有元件（正式建置不包含這一頁）。
  - **新增圖解的規則**：每張圖都要在解釋內容本身（不放裝飾圖）；圖上的短標籤必須由既有文字提煉，寫在 `src/content/` 對應欄位並註明出處（例如打破慣性的 `visual.loop`）；原文沒有描述「循環」時不硬畫循環圖；沒有數據的概念圖標示「示意圖，非實際數據」；圖表只用研究實際報告的數字並附出處；每張圖要有 `role="img"`＋完整 `aria-label`。
  - 圖示對應放在呈現層：`components/pattern/visualIcons.ts`（打破慣性）、`components/habits7/visualIcons.ts`（7 Habits 情境標籤）；水彩插畫在 `WatercolorSpot.tsx` 的 `SPOTS` 新增一個主題即可。
  - 圖解元件的根元素帶有 `data-visual`，量測「每個螢幕是否有圖解」時使用。
- **標題**：較長的中文標題用 `<Phrased text={...} />`，只在標點後換行，手機上不會出現單字落行。
- **響應式**：以手機為基準撰寫，再用 `sm:`（640px）、`md:`（768px）、`lg:`（1024px，顯示側邊欄）、`xl:`（1280px，顯示右側面板）往上加。

### 彩蛋

- 在任何頁面（不在輸入框時）用鍵盤打出 `rewire`。
- 解鎖新的徽章、植物或景觀時，會飄下葉子小小慶祝一下。

## 部署到 GitHub Pages

網站的建置結果放在 `docs/` 資料夾，GitHub Pages 可以直接提供，不需要 GitHub Actions。

**第一次設定（只需要做一次）**
1. 到 GitHub 儲存庫 **Settings → Pages**。
2. **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. **Branch** 選 **main**，資料夾選 **/docs**，按 **Save**。
4. 等 1～3 分鐘，網站會出現在 `https://mindy9805.github.io/Rewire/`。

**之後修改內容時**
1. 修改 `src/` 中的檔案（例如 `src/content/` 的文字）。
2. 在本機執行 `npm run build`，`docs/` 會自動更新。
3. 把修改的檔案與更新後的 `docs/` 一起提交（commit）並推送（push）。

**自動檢查**：`.github/workflows/check.yml` 會在每次推送時執行程式碼檢查、型別檢查、單元測試與建置，並確認提交的 `docs/` 與原始碼一致。它只做檢查、不會部署，所以不需要更改 Pages 的設定。

**路徑說明**：Vite 使用相對路徑 `base: './'`，搭配 HashRouter（網址形如 `/rewire/#/learn/ch1`），因此放在任何子路徑都能正確載入，重新整理或分享深層連結也不會出現 404。

## 資料與隱私

- 資料結構帶有修訂號（`revision`，目前為 4）。
- **共用活動紀錄**（`src/lib/activity.ts`）：每一筆實際保存的練習或紀錄以「來源＋紀錄 id」計算一次，同一筆編輯不重複計算；瀏覽、抽卡、轉轉盤本身不計入。心智花園的成長點、收藏徽章與儀表板「自願參與」統計都使用這份定義。已解鎖的徽章與植物另存於 `unlocks`，不會因中斷或刪除紀錄而收回。讀取舊版資料或舊備份時，會自動補齊新模組的預設值，不會刪除既有紀錄。

- 所有筆記、情緒紀錄、練習內容與行動計畫只存在瀏覽器 LocalStorage（鍵名 `rewire:v1`），不會傳送到任何第三方服務。
- 字型自架（`@fontsource-variable/*`，於 `main.tsx` 載入），不連到 Google Fonts。語音朗讀使用瀏覽器內建的 SpeechSynthesis；部分聲音（如 Chrome 的 Google 國語）為線上聲音，文字會送到該公司合成，聲音選單以「連線」標示，並已寫入「資料與隱私」。
- 清除網站資料、更換裝置或使用無痕模式可能導致紀錄遺失，請在「資料與隱私」頁定期匯出備份。

## 內容與研究原則

- 學習解說皆為重新組織的原創文字，不複製書籍或影片中的長篇內容。
- 研究來源列出作者、年份、期刊與 DOI；開發環境無法即時連線 doi.org 比對，建議維護者點擊連結再次確認。無法確認的欄位（例如《Rewire》各版本的出版社與年份）標示「待查證」。
- 模擬器與曲線圖皆標示「概念示意／概念模型」，不代表真實神經變化數據。
- 本站練習不能取代專業心理或醫療協助（台灣 1925 安心專線，24 小時）。

## 公開前的法務與文字守則（維護時請遵守）

- **名稱**：不使用 `7 Habits` 當功能名稱（導覽用「高效能生活」）；只在引用書目時寫書名。不使用書封、書內圖表或原文；章節順序不對照原書。第 7 章叫「七個日常練習」，不用「七個…工具」。學習區叫「主題學習」，不叫「導讀」。
- **聲明**：全站頁尾必須保留「非官方、非醫療、求助專線」；完整說明在 `#/about`。
- **字眼**：不用保證式或療效字眼（如「重塑大腦」「療癒」「保證」「一定」）；批判性思考章節為了說明而引用除外。
- **隱私**：沒有第三方請求（字型已自架）。新增任何外部連線前，必須同步更新「資料與隱私」。朗讀線上聲音以「連線」標示。
- **舊資料相容**：筆記標籤舊值 `7 Habits` 仍會被辨識（`isH7Tag`），新資料使用「高效能生活」。
